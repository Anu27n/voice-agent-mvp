Idle

Demo mode. No API keys are configured, so speech recognition is scripted (it "hears" a fixed list of questions), replies come from a rule-based stand-in for the LLM, and the voice is a synthetic hum. Typed messages skip the scripted recognition, so type a question to try the real tools.

Press Start Call and allow microphone access. Try:

  • "What time is it in Tokyo?"
  • "Where is order A1001?"
  • "What's the weather in Paris?"
  • "What's 18 percent of 240?"
  • "Thanks, that's all." (the agent hangs up)

Shortcuts: Esc end call, M mute/unmute, / type a message.
